O Specsfy conecta intenção, especificação, implementação e evidência. Sua
identidade combina o petróleo e o turquesa da Promovaweb com violeta, variação
que diferencia o trabalho de modelagem e especificação.

Este diretório é a fonte normativa da identidade visual do Specsfy.

## Conceito visual

O símbolo preserva as **três camadas com código**. A placa superior representa
a especificação executável; as camadas inferiores representam decisões e
evidências que permanecem ligadas durante a entrega.

## Arquivos oficiais

| Arquivo | Uso |
| --- | --- |
| `logo/icon.svg` | ícone principal com placa petróleo |
| `logo/icon-light.svg` | ícone transparente sobre fundo claro |
| `logo/icon-dark.svg` | ícone transparente sobre fundo escuro |
| `logo/logo-light.svg` | assinatura horizontal sobre fundo claro |
| `logo/logo-dark.svg` | assinatura horizontal sobre fundo escuro |
| `logo/icon.png` | fallback raster de 512 × 512 px |

Preserve 12,5% de área livre ao redor do ativo. O tamanho mínimo é 28 px para
o ícone e 130 px para a assinatura horizontal.

## Sistema digital

- `colors/palette.json`: fonte editável da paleta;
- `tokens.json`: tokens agnósticos;
- `global.css`: webfontes, variáveis CSS e troca de tema;
- `tailwind-theme.js`: extensão para Tailwind CSS;
- `accessibility.md`: relatório de contraste;
- `typography/README.md`: hierarquia tipográfica.

## Regras para agentes

1. Violeta identifica especificação; turquesa mantém o vínculo institucional.
2. Use tokens semânticos e a variante correta para light ou dark mode.
3. Não remova, reordene ou separe as três camadas.
4. Não aplique filtros, gradientes, sombras, rotações ou deformações.
5. Estado e evidência devem ter rótulo textual, não apenas cor.

A assinatura verbal canônica é **Especifique. Comprove. Entregue.**
