# Definir o MVP por milestones

Use `$specsfy-mvp-milestone-interviewer` (`specsfy-mvp-milestone-interviewer`)
para conversar até chegar ao menor
produto utilizável. A skill adapta as perguntas às suas respostas, registra
apenas o que você confirmar e propõe milestones com condições de saída.

## Quando usar

Use antes de criar um conjunto de specs para um produto novo ou quando o MVP
ainda não tem uma jornada confirmada.

## Como descrever a tarefa

Peça: “use o entrevistador de MVP para organizar os marcos do meu sistema de
leads”.

## Exemplo passo a passo

```text
Ideia → entrevista adaptativa → síntese aprovada → M01, M02 e specs vinculadas
```

## O que esperar

Ao final, aprove a síntese antes de criar as relações entre marcos, specs e
backlog.

## Erros comuns

- pedir tarefas técnicas antes de confirmar a jornada do MVP;
- encerrar a conversa sem condição de saída verificável.
